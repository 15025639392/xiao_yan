# VRM Avatar Asset

The current spike model is stored at `xiaoyan.vrm`.

Source: `cryptovoxels.vrm` from `madjin/vrm-samples`.

License note from the source repository: the repository distinguishes VRoid sample models with conditions and CC0 models. Treat this file as a temporary spike asset until the final Xiao Yan model license is confirmed.

The app loads `/avatar/xiaoyan.vrm` only when the persona avatar feature is enabled. If the file is absent, the UI keeps the state-mapping preview and shows a model-loading notice.

Asset requirements:

- Confirm the VRM license allows local desktop use and redistribution.
- Prefer a compressed model and texture set for the desktop shell.
- Keep this folder to the active model during the spike; avoid adding a model library here.
