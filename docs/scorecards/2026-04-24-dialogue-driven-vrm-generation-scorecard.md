# 对话驱动 VRM 生成需求质量评分卡

## 1) 评分维度

### A. 完整性（0-25）

- 目标与成功指标：5/5
- 范围与非范围：5/5
- 依赖与约束：5/5
- 待确认问题状态：5/5
- 关键风险识别：5/5

### B. 可执行性（0-25）

- 任务可独立执行：5/5
- owner 明确：5/5
- 优先级与顺序明确：5/5
- 依赖与阻塞条件明确：5/5
- 工时估算合理：5/5

### C. 可验收性（0-25）

- Done 标准可验证：5/5
- 验收用例测试化：5/5
- 覆盖功能与回归：5/5
- 覆盖性能或兼容：5/5
- 验证方式可执行：5/5

### D. 风险覆盖（0-25）

- 技术风险缓解：5/5
- 上线风险门禁：4/5
- 回滚触发条件：4/5
- 回滚路径：5/5
- 上线后观测指标：5/5

## 2) 门禁阈值

- 标准模式门禁：总分不低于 80，且关键未知项均有 owner 和截止时间。

## 3) 评分记录模板

- 模式：标准
- A. 完整性：25
- B. 可执行性：25
- C. 可验收性：25
- D. 风险覆盖：23
- 总分：98
- 是否通过当前门禁：是
- 不通过时补齐项（owner + 截止时间）：当前已通过；资产模板授权、商用策略和后续资产库范围由用户确认
